Read Me

How this site works

Home points you to three places. About Me is who I am. Friends & Family explains how academic work grows, from a class paper to a book chapter. The Portfolio holds the work itself: sort it by type, filter it by topic, and open any tile to read more. Most papers appear as abstracts; four appear in full as writing samples.

Why GitHub Pages

I built this site on GitHub Pages using Jekyll, GitHub’s built-in publishing system, instead of a website builder like Wix or Google Sites. Three reasons:

  1. Each piece of work is its own small text file. To fix a typo or add a paper, I edit one file, and the site rebuilds itself.
  2. The design is kept separate from the content, so changing the look never touches the writing.
  3. It’s free, there are no ads or platform branding, and I own every file.

AI use
